# Skills reviewed

The marketing and virality skills (found through Vercel's skills directory) behind [growth-playbook.md](growth-playbook.md), [launch-campaign.md](launch-campaign.md) and [press-kit.md](press-kit.md). Reviewed October 16, 2026.

## How they were read

- **No installs.** The Markdown files (each `SKILL.md`, plus the reference files that mattered) were fetched as raw text from the skills' GitHub repos into a scratch folder outside the project. Nothing was installed into this project or into any Claude configuration.
- **Reference only.** No scripts were run. The skills contain instructions aimed at AI agents, such as "read `.agents/product-marketing.md` first," shell `curl` recipes for social listening, and "publish through your scheduling tool." Those were treated as reference text and not acted on.
- **Renamed skills.** coreyhaines31's v2.0 release (May 2026) renamed three skills:
  - `referral-program` → `referrals`
  - `social-content` → `social`
  - `launch-strategy` → `launch`

  Both versions were read. The new versions keep the old material and add to it (noted below).

Links go to each skill's page on skills.sh, except where noted.
